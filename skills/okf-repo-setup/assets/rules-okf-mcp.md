
## У бандла есть внешний потребитель

`__MCP_DIR__` — MCP-сервер, через который заказчик спрашивает ИИ-агента «как сейчас работает продукт». Отвечает он ровно этим бандлом, вшитым в образ. Отсюда: **устаревший концепт — это неверный ответ заказчику**, а обновление `okf-bundle/` пересобирает и передеплоивает сервис. Что видит заказчик (и пользователь) — `__MCP_DIR__/src/project.ts`; гарантии закреплены тестами (`cd __MCP_DIR__ && npm test`), они гоняются по реальному бандлу.
