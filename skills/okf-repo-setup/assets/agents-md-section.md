## Knowledge bundle

OKF-бандл знаний по проекту лежит в `./okf-bundle/`. Начинать с `okf-bundle/index.md` (или `okf-bundle/overview.md`), дальше подгружать отдельные концепты по мере надобности — читать бандл целиком не нужно.

**Правишь код — обнови затронутые концепты в той же ветке**, отдельным коммитом `docs(okf): ...`. Если поведение не менялось (рефакторинг, эксперимент), добавь в сообщение коммита с этим кодом строку `okf: n/a — <причина>`. Это правило проверяет CI на PR (`python3 scripts/okf/drift.py --gate`), кто бы ни писал код.
